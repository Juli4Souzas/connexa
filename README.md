# Conexxa 💻

O **Conexxa** é uma plataforma web voltada para a **criação e gerenciamento de grupos de estudo**, com funcionalidades como cadastro, login, criação e participação em grupos.

O projeto foi desenvolvido para a disciplina de **Engenharia de Software**, tendo como principal objetivo proporcionar experiência prática com **Git, GitHub, controle de versões, branches, commits, trabalho colaborativo e tecnologias auxiliares**.

### Tecnologias

* HTML5
* CSS3
* JavaScript
* Git e GitHub
* Tecnologias auxiliares utilizadas no desenvolvimento

O Conexxa combina o desenvolvimento de uma aplicação funcional com a **aplicação prática de conceitos e ferramentas do desenvolvimento de software**.

> Projeto acadêmico desenvolvido para fins educacionais.
